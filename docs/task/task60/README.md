# Task60-Task65 执行切分

## 目标

把 [Task59](D:/文件/project/AIParticipatingAutonomousTradingSystem/docs/task59/README.md) 切成可以连续实施的子任务，并按依赖顺序推进。

## 任务拆分

### Task60：收益验证数据面

目标：

- 建立执行质量与收益归因的最小可用数据面
- 暴露 operator 可读报表接口

范围：

- 新增执行质量报表
- 新增收益归因概览
- 复用现有 audit / execution / fill outcome / portfolio 数据

验收：

- 可以查看每笔 fill 的时间链路、价格链路、费用、已实现盈亏
- 可以查看近期成交的收益概览

### Task61：策略分层验证

目标：

- 把收益结果按市场状态、方向、动作、品种分层

范围：

- 按 regime / symbol / side / execution_action 分层统计
- 给出每个切片的净收益、费用、滑点、样本量

验收：

- operator 可查看分层表现
- 能识别明显退化的切片

### Task62：执行质量治理

目标：

- 识别策略收益是否被执行层吃掉

范围：

- 高延迟、高滑点、高费用订单标记
- 订单质量异常聚合

验收：

- 能识别高成本订单模式
- 能输出执行质量摘要

### Task63：试盘 runtime profile

目标：

- 准备小资金前向验证运行配置

范围：

- 新增小资金 profile
- 新增试盘约束
- 新增自动停机阈值

验收：

- runtime profile 可直接启用
- 超阈值可自动停机

### Task64：周期性前向验证报表

目标：

- 建立周报/月报输出基础

范围：

- 固化日/周收益摘要
- 固化试盘复盘模板

验收：

- 可以形成标准化验证报告

### Task65：放量准入评审

目标：

- 给出是否扩大资金规模的客观规则

范围：

- 放量阈值
- 回退条件
- 审批与留痕

验收：

- 能形成“继续 / 缩容 / 停止”的书面决策
