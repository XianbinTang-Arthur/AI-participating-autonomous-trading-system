# Recent No-Order Provenance Density Gate Truth

## Business Objectives And Boundaries

Add a read-only runtime truth gate that confirms the latest directional no-order candidate drilldown, current decision lifecycle, recent no-order decision window, and execution-science continuity all refer to the same current decision and remain internally consistent.

This task does not change strategy, risk gates, execution, AI provider behavior, symbol, venue, schema, promotion, release, tuning, timeframe plumbing, or live order behavior.

## Module Responsibilities And Domain Model

`scripts/runtime_truth_report.py` owns the summary. It consumes existing compact runtime truth surfaces:

- `recent_directional_no_order_candidate_drilldown_context_truth`
- `decision_lifecycle_provenance_continuity_truth`
- `decision_lifecycle_execution_science_continuity_truth`

The new surface reports a binary gate under `recent_directional_no_order_provenance_density_gate_truth` and exposes flattened fields in `project_live_runtime_facts`.

## Input/Output Interfaces

Input is in-memory runtime truth dictionaries already generated by the runtime truth report. Output is a compact dictionary with status, smallest missing field, current decision identity checks, recent-window counts, latest-only drilldown scope, terminal pretrade status, and payload sequence status.

No raw DB payloads, exchange payloads, secrets, tokens, or connection strings are emitted.

## Database Schema / Tables / Indexes / Constraints

No schema, table, index, or constraint changes.

## Transactions, Consistency, Concurrency

No writes and no transactions are introduced. Consistency is inherited from the runtime truth snapshot already collected by the report.

## Authorization, Authentication, Data Security

The feature does not add credentials or bypass authentication. Existing effective AI runtime auth-gating remains intact. The output explicitly keeps `raw_payload_exposed=false`.

## Error Handling And Idempotency

The summarizer returns a structured status and smallest missing field for exposed raw payload, missing upstream surfaces, latest decision identity mismatch, non-no-order current decision, fills inside the recent no-order window, missing terminal pretrade context, or missing continuous payload sequence evidence. The function is deterministic for a given report input.

## State Transition And Lifecycle

No trading state transitions are changed. The surface only classifies evidence continuity across already-read runtime truth surfaces.

## Caching And Performance

The summarizer operates on already-available compact dictionaries and adds no DB queries. Runtime cost is negligible compared with existing runtime truth generation.

## Logging, Monitoring, Auditing

The surface improves auditing by making the current decision identity match explicit across candidate drilldown, lifecycle provenance, and execution-science continuity. It also keeps the historical candidate drilldown scope explicit as latest-decision-only.

## Testing Strategy

Unit tests cover:

- Verified recent no-order provenance density gate.
- Latest decision identity mismatch classification.
- Flattened `project_live_runtime_facts` exposure.

## Migration, Rollback, Compatibility

Rollback is a code revert of this read-only surface. Existing report fields remain compatible and unchanged.

## Configuration And Environment Isolation

No configuration or environment changes.

## Code Organization And Dependencies

No new dependencies. The implementation follows the existing runtime truth summarizer pattern.

## Deployment And Acceptance Criteria

Acceptance is binary:

- `recent_directional_no_order_provenance_density_gate_truth.status` is `verified_recent_directional_no_order_provenance_density_gate` on fresh runtime truth.
- `raw_payload_exposed=false`.
- Latest decision identity is consistent across candidate drilldown context, lifecycle provenance, and execution-science continuity.
- Recent window has all decisions no-order expected and zero fills.
- Focused unit tests, lint, full unit suite, commit, push, deploy, and post-deploy smoke pass.
