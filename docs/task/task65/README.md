# Task65：放量准入评审机制

> 项目定位声明：本文件默认服从 AATS 的统一目标：在严格风控、可审计、可恢复、可治理前提下，通过自动化交易追求长期稳定盈利，为 AI 的持续自治与终身发展积累资本。详见 [项目定位声明](../../../docs/project_positioning.md)。


## 目标
- 在现有前向验证、试盘守护和恢复门禁之上，补齐“是否允许进入下一档资金评审”的统一结论。
- 为 operator control plane 增加人工评审留痕，避免放量决策只停留在口头结论。
- 同步补齐前端展示与操作入口，保证值班人员能直接看到结论并记录人工评审。

## 设计原则
- 不重复实现已有收益和异常报表，直接复用 `forward_validation_report()` 与 `trial_guard()`。
- 不直接自动放量，本任务只输出准入结论并记录人工评审。
- 放量结论必须同时考虑：
  - 前向验证表现
  - 试盘守护状态
  - 恢复与风控状态
  - 当前活动阻断项

## 主要交付
- 新报告接口：`GET /reports/scaling-readiness`
- 新人工评审接口：`POST /system/scaling-review`
- 新 operator action：`capital_scale_review`
- 策略页新增“放量准入”卡片和人工评审按钮

## 结论语义
- `approve_scale_up`
  - 最近多个周期表现稳定，且恢复、阻断、试盘守护状态正常，可进入人工放量评审。
- `continue_small_capital`
  - 继续保持小资金试盘，先积累样本。
- `shrink_trial`
  - 当前边际转弱，建议先缩容。
- `pause_trial`
  - 当前不满足继续试盘或放量条件，建议暂停。

## 验收要点
- 报告接口能返回结论、原因、要求、最近人工评审和最新前向验证。
- 人工评审动作能落到 `OPERATOR_ACTIONS`。
- 前端策略页能展示放量准入结论，并允许记录人工评审。
