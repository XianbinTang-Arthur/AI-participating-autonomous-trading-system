系统总览

概览

查看当前交易状态、风险阻断、仓位与收益、以及最近一次决策结果。

最新决策摘要

显示最新一次交易判断、目标仓位，以及是否允许继续执行。

系统状态

健康度、是否就绪、以及交易权限是否被阻断。

账户与收益概览

展示账户权益、持仓方向、风险敞口、已实现与未实现收益。

当前阻断项

说明当前是什么原因阻止了交易，或让系统进入降级状态。

等待数据

恢复与基线

显示恢复状态、当前基线是否可信，以及是否可以安全恢复交易。

核心指标

查看决策次数、订单数、成交数、拒单数和对账异常数等核心运行指标。

最近运行时间线

按时间查看最近的状态变化、对账校验和异常信号。

决策排查

决策

追踪一笔交易想法从市场上下文到风控、执行和审计的完整链路。

最新决策详情

查看最近一次决策的目标仓位、风控结果和最终执行结果。

按决策编号查询

输入决策编号后，可在右侧抽屉查看完整链路明细。

最近决策

显示短期滚动决策历史，方便人工复核。

执行监控

执行

查看当前交易提交通道、最近订单、最新成交和执行异常。

执行概况

显示当前提交通道、执行是否就绪、最新订单、最新成交和恢复状态。

订单 / 成交查询

输入订单号或成交号后，可直接查看对应详情。

最近订单

查看订单状态、提交方向、数量和对应的决策来源。

最近成交

查看最新成交回报、成交价格、数量和手续费信息。

执行异常

查看最近的阻断、拒单和执行失败原因。

诊断与排障

诊断

查看对账、回放、账户数据新鲜度、阻断历史和系统完整性。

对账摘要

显示最新对账级别、差异摘要和校验结果。

恢复与基线

显示当前恢复状态、基线接管情况和人工修复姿态。

回放状态

显示最近的回放校验结果、基线切换情况和偏差数量。

账户状态

显示账户后端、数据新鲜度、是否就绪，以及账户侧阻断原因。

阻断历史

按时间查看最近的阻断快照及其对人工操作的影响。

运行指标

查看决策频率与核心运行计数器。

运行配置

运行配置档

安全切换现货或合约运行姿态，并查看版本历史、预检查结果和重启激活要求。

当前生效状态

查看当前以哪份配置为准、正在生效的版本、待激活版本，以及是否需要重启。

托管重启状态

查看托管启动器的心跳、最近一次重启原因，以及配置激活结果。

创建或更新草稿

先复制当前运行配置到草稿，再只调整允许人工安全修改的字段，通过预检查后再进入待激活状态。

改动影响

查看这次改动的人类可读说明、风险分类，以及是否适合进入待激活状态。

版本历史

查看不可变版本记录，以及当前生效版和待激活版的标记。

身份管理

操作员

用管理员会话管理数据库中的只读、操作员和管理员账户。

认证状态

查看当前浏览器认证方式、初始化状态，以及是否具备管理员权限。
