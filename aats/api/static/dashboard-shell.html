运行模式 (ai_operating_mode) 语义

决定 AATS 是否真下单的第一个开关是 ai_operating_mode。配置层默认值由 .env.*.live / strategy profile YAML 决定；运行时 admin 可通过 AI 配置页的三个按钮临时覆盖（"仅按基础策略运行 / AI 辅助决策 / AI 决策者"）， 需要 AATS_ALLOW_UI_OPERATING_MODE_OVERRIDE=true 才放行。

canonical mode decision_authority 实盘行为
baseline_only reference_only 不调用 AI · 纯 baseline 决策 · 是否下单由 baseline 信号决定
ai_assisted advisory 按 baseline 下单,AI 仅咨询
ai_decision_maker final_decision AI 主导下单 · baseline fallback

运行模式与策略档位自动换档（strategy_profile_auto_control_enabled） 是两个完全独立的开关——前者管 AI 在单次决策里扮演什么角色，后者管 6 个档位 由谁选。详见 docs/governance/runtime_trading_mode_semantics.md §1-§3。
